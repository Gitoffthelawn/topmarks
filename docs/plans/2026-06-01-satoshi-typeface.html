Plan · Topmarks

Satoshi as the UI typeface

Adopt Satoshi as the new-tab page and settings typeface — a geometric grotesque with more personality than the system stack — with the big bold clock (shipping in parallel) as its loudest moment. Cookie stays as the script accent.

Built 2026-06-01 shared · both stores

UX What changes

  1. All body and UI text on the new-tab page and the settings panel renders in Satoshi instead of the system sans, with the system stack kept as the fallback (no FOIT, no broken layout if the font fails to load).
  2. The clock inherits Satoshi and leans into its heaviest weight (900 / Black) for the "big bold clock" look the center-widget plan calls for — replacing that plan's "bold system sans" decision.
  3. The Cookie script font is untouched — it stays on the .bmc-link / brand accent.
  4. No visible setting; this is a global typographic change, applied for everyone.

1 Why / context

The page already self-hosts one bundled font (Cookie) the canonical way: a @font-face in newtab.css, a <link rel="preload"> in newtab.html, and a recursive copy of assets/fonts/ into each store's dist/ at build time. Satoshi rides the exact same rails — no new build machinery, no remote fetch (which extension CSP forbids and which would leak a request per new tab).

Satoshi ships as a single variable file carrying the whole weight axis (300–900). The app today uses weights 400 / 600 / 800 and the clock wants 900 — all covered by that one file, so the minimum footprint is literally one .ttf. The other 12 family files that were pasted in have been removed.

3 Verification

  • npm run build both packages — validateDist confirms the font ships; type-check is unaffected.
  • Load unpacked: body text and settings render in Satoshi; the clock is heavy/black; Cookie still on the brand link.
  • Throttle/deny the font once → text falls back to system sans cleanly (swap, no invisible text, no layout jump).
  • Check the one italic spot (.empty-state, the "no bookmarks" line) — synthesized oblique looks acceptable at 0.6 opacity.
  • Glass + Classic, light + dark, all legible over a wallpaper at the 13px body size.

Decisions

✓ One variable file — the minimum

Satoshi-Variable.ttf alone covers 400/600/800/900. The 12 static + italic files have been removed.

✓ Clock at weight 900

Satoshi Black gives the "big bold clock" its punch, overriding the center-widget plan's "bold system sans" note.

✓ Keep Cookie

The script accent on .bmc-link stays — Satoshi is the workhorse, Cookie the flourish.

✓ No italic file

The lone italic use (.empty-state) is low-emphasis; let the browser synthesize an oblique rather than bundle a second ~130 KB variable-italic file.

✓ TTF, matching Cookie

Consistent with the existing self-hosted font and with what was provided. See the open item on woff2.

Open items

? woff2 to shrink the payload

The variable TTF is ~124 KB; the equivalent woff2 is typically ~40 KB. Fontshare publishes woff2, but it isn't reachable from this sandbox. Optional follow-up: drop in Satoshi-Variable.woff2 and switch the src — smaller download, faster first paint. Not required to ship.
